# Будущие адаптеры

Ollama предоставляет inference. Для включения в ADW нужен отдельный agent loop: вызов модели, инструменты, разрешения, ограничение шагов/времени, нормализация событий и независимый Verifier. Сам сервер Ollama не реализует интерфейс coding agent. В этапе 02 такой адаптер не добавлен.

Cursor остаётся экспериментальным направлением. Подключение возможно через официально поддерживаемый CLI или extension bridge после проверки конкретной версии. Требуются discovery, capability manifest, versioned fixtures, session lifecycle, ошибки и отмена. Управление внутренним UI и парсинг ANSI как основной протокол не планируются; полноценная интеграция не заявлена.
