# ADW 06 — Independent Review Engine Implementation Plan

> **For agentic workers:** REQUIRED: Use `@superpowers:subagent-driven-development` (if subagents available) or `@superpowers:executing-plans` to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Review Engine that runs a **different** agent/session than the executor on the integrated diff, produces structured remarks (code/security/visual placeholders), and can block `ready_for_review` → human with blocking findings.

**Architecture:** `packages/supervisor` gains a `ReviewEngine` module (or `packages/review`). After verifier green, Supervisor starts reviewer adapter with read-only bundle + unified diff + check evidence refs. Reviewer session id ≠ executor session id; prefer different `agentId` when two adapters available. Remarks stored as Findings with `verificationStatus`. Final verdict aggregated only after checks + review return.

**Tech Stack:** existing CLI adapters, git diff, Zod `ReviewRemark` schema, Vitest + fake adapters.

**Depends on:** chunk 05 (orchestrator), 02 (adapters), 01 (diff from worktree).

**Out of scope:** Playwright visual review (chunk 07 supplies screenshots into evidence), Desktop UI, parallel multi-review fanout beyond sequential code then security.
